# Sungjae Lee — research homepage

Personal academic homepage at **https://sungjelly.github.io/**.

## Edit the homepage

The website is a single, self-contained `index.html` file. It uses plain HTML and CSS, with no installation, build step, JavaScript dependency, analytics, or external fonts.

1. Open `index.html` on GitHub and choose **Edit this file**.
2. Change the text in the About, Selected research, Background, or Elsewhere sections. The colors and responsive layout are defined in the `<style>` block near the top.
3. Commit to `main`. GitHub Pages publishes the updated page automatically.

## GitHub Pages configuration

In **Settings → Pages**, use **Deploy from a branch**, branch **main**, folder **/(root)**. The repository name must remain `sungjelly.github.io` to use the address above.

## Suggested next additions

- Add a confirmed current affiliation and the email address you want to make public. The profile section has a comment marking the location.
- Add a public CV with private details removed. Upload it as `assets/cv.pdf`, then add a link to it in the profile.
- Add paper or preprint links once public, using the exact title, authors, venue, year, and status. Do not label a submission as an accepted publication.
- Replace the clearly labeled concept illustrations with selected research figures. Give each figure useful alternative text and a brief caption stating what the result shows.
- For each project, describe your own contribution, one well-supported result, and the evaluation setting and limitations.

To add a public email link, use `<a href="mailto:YOUR_PUBLIC_EMAIL">Email</a>`. To add a CV link, use `<a href="assets/cv.pdf">CV (PDF)</a>` after uploading the file.

Keep the page title, description, and footer update date in sync with significant edits. Check both narrow and wide screens after layout changes. The two project drawings are conceptual illustrations, not experimental results.
